# 保持一致的制作约定

1. **不可丢失的用户要求**：正式片名「大肥鱼我的家乡」；第一次出现角色即是抱拳／胸前合手造型；使用用户原音频和已确认的英文歌词；工程与游戏独立。
2. **角色锁定**：长深蓝发、青蓝发尾、蓝眼、鲸鳍耳、单根弯曲呆毛、白色女仆头饰与蓝蝴蝶结、深蓝金线裙装、白围裙和鲸尾。不同镜头复用同一关键帧美术，闭眼与睁眼图来自同画面编辑，减少脸型和服装漂移。
3. **叙事载体**：人的输入与她的响应产生世界。会话、工具调用、几何和角色之间有因果联系；没有真实服务连接，不把虚构运行日志装成真实模型内部数据。
4. **色彩**：近黑、深海蓝、青白。人类皮肤和角色脸部保留自然肤色；不添加粉紫霓虹、杂乱 HUD 或彩虹频谱。
5. **镜头**：先做低成本抽样，再检查一段真实副歌视频，最后渲染全长。绘制解析三维几何与角色网格动画，而非每一帧重新生成图像，保证时间连续性和可修订性。
6. **音乐对应**：真实节拍与频带特征保留在 `analysis/`；第一人声约 15.96 秒、第一副歌约 63.7 秒、末副歌约 139.78 秒。长间奏以递归几何和字符角色推进，不虚挂歌词。末副歌的「Your hands」对应指尖镜头。
7. **节制**：保留可读的暗部和呼吸段；辉光、色差与颗粒为低强度统一后期。纯代码镜头按样张调整了点、线亮度，避免只有立绘看得清。
8. **验证与限制**：全片本机离线渲染，模型只辅助音频分析。图像网格的头发和裙摆运动不能被描述为完整角色表演，参数化海面不能被描述为电影级物理流体。静帧总览不能代替动态观看；播放量不可由制作流程保证。
