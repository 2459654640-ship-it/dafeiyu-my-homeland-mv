# v2：终端动效重做

上一版的失败：立绘平移／放大占据主画面，线框形态重复，终端只是说明性装饰，镜头间没有有力的动态衔接。

v2 保留用户指定的「大肥鱼我的家乡」与抱拳开头，重新搭建以终端为舞台的动态系统。此目录独立于上一版，不覆盖其源文件。

## 实际参考

网络更新后，通过 B 站公开播放接口取得了用户给出的参考视频 360P 公开流，在本地以六秒及四分之一秒间隔查看实际画面和动效。只用于研究，不将参考影片片段或音频打包、上传或混入本片。

v2 重新实现自己的会话、排版、几何、字形栅格和转场。没有导入参考仓库的出片代码。参考仓库及作者署名保留在根工程 SOURCES 中。视觉借鉴的重点是终端层次、字形图像、镜头密度及内容驱动的界面变化；剧情、歌词、编排、动态字段和角色元素由本片构建。

## 生成素材的用途

- `character-atlas.png`：四格可合成角色素材，分别为抱拳睁眼、闭眼、指向、张开双手。
- `world-atlas.png`：鲸、岛屿、轨道城市、种子晶体、行星及鲸尾六个独立元素，透明背景。
- 裁出的素材参与局部骨骼控制、像素网格变形、表情／动作状态机、三维深度浮雕、字符粒子以及卫星窗口合成。没有使用整张背景插画作为推拉镜头。
- 人物是生成关键姿态配合代码形变与状态动画，不是生成视频模型或完整三维人体骨骼演出。

## 同时运行的动态层

1. 歌词与会话时间轴、逐词跳动标签及活动工具状态。
2. 角色眨眼、局部肩腕控制、发尾网格以及指向／展开双手姿态。
3. 海面解析波叠加、Lorenz 数值积分轨迹、递归几何、三维星图及图像深度浮雕。
4. 半透明多股流线、沿流线运动的数据包、前后景字符粒子和轨道中的世界窗口。
5. 上一镜头内容实际切成碎片飞出，或折叠成竖向窗片，留下承接下一镜头的种子。
6. 低强度辉光、节拍冲击、局部显存行错位、点击反馈和逐格解码显影。

字形图像采用 native 1920×1080 排版，避免先画低清图片再放大。纯终端字形与像素角色保留有意的采样颗粒。

