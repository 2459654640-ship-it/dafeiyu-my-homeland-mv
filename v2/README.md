# 大肥鱼我的家乡 / v2 终端动效重做

此版本按用户反馈重做：终端和字符特效为主，窗口、数据、角色元素持续变形、飞行和重组。使用两张新生成的模块素材图集，而非将完整插画作为推拉镜头背景。

影片保留完整原音频、抱拳问候、正式片名与英文／中文字幕。前作 v1 的视频仍作为历史文件保留，但不是此版本。

## 制作内容

- 44 个明确编排的镜头段落，逐词歌词时间轴驱动字幕标签，真实音频频带与节拍驱动部分运动。
- 角色四个生成姿态、眨眼、局部肩腕控制、发尾像素网格形变；模块化鲸、岛屿、空间站、晶体、行星和尾鳍。
- 数值积分的三维流线与数据包、解析海面、递归几何、图像深度浮雕、字形重组、卫星窗口与窗口碎片／折叠转场。
- 连续运动的前后景字符粒子、短节拍冲击、局部显存行错位、三维终端镜头以及低强度辉光。
- 角色不是完整三维人体骨骼动画，也没有调用生成视频服务；各姿态和局部形变通过代码组合。分析与计算画面属于虚构世界生成界面，不是真实模型内部诊断。

## 在 Linux 复现

解压后，在 `dafeiyu-mv-v2` 目录执行：

```bash
python3 -m venv .venv
.venv/bin/pip install -r v2/requirements.txt
.venv/bin/python v2/source/film.py
```

需要 `ffmpeg` 与机器安装的 Noto Sans CJK、DejaVu Sans Mono 字体。没有模型下载、API 密钥或游戏工程依赖。

生成局部动画或抽样画面：

```bash
.venv/bin/python v2/source/film.py --ranges 63.7:80.033333 --output v2/output/chorus.mp4
.venv/bin/python v2/source/film.py --stills --times 2,9,64.5,68,72,77,97,152
```

每一帧由歌曲时间决定，随机种子固定；可以按时间直接重渲染局部，不需要推翻整条时间轴。

主要修改位置：`film.py` 为分镜、终端会话、逐词字幕和主要画面；`fx.py` 为多层动态、碎片转场和镜头；`ui.py` 为终端字形、像素风格及角色／物件局部控制；`fields.py` 为三维场、数值轨迹和资产深度浮雕。
