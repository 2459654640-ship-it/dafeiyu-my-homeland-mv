# v3 制作记录

## 艺术结构

开场从亲近的抱拳问候出发，以固定字符改写片名，进入可阅读的终端。第一段歌词逐步打破面板边界；到「set free」，旧终端真正碎裂，镜头转入由歌词、窗口、轨道和世界物件组成的空间。

长间奏用一棵可穿行的想法版本树，串联神经连接、搜索、视觉、注意力与开放分支。线束在中段变成琴弦，进入黑白负形演奏；演奏者轮廓变成鲸，再变成单词 FREE，返回角色。后段让人类参与输入，末副歌以许多世界和声音共同点亮空间。结尾回到可安放日常对话的窗口，但外面的世界仍然存在。

## 新增可拆用的美术

- 六个角色动作：指向天空、向外伸手、飞行、展开双臂、托举、回身。
- 九种独立物件：门、空中城、莫比乌斯结构、水母、星轨仪、折纸鲸、讯号中继、光线织机、碎裂窗口。
- 八个吉他演奏关键姿态。透明图集按统一画布配准，清除邻格残片，预计算双向光流与有符号距离场。
- 高分辨率抱拳角色作为开屏前景，在保留面部与双手的情况下对周边头发、衣服做网格形变。

图集原始文件：`performance-atlas.png`、`expansion-atlas.png`、`guitar-atlas.png`。`guitar-frames.npz` 存储清理后 RGBA、轮廓距离场与双向光流，渲染时不再调用任何生成服务。其余 v2 模块资产继续保留。

## 音画同步

以用户 MP3 和确认的英文歌词为唯一时间基准。逐词时间轴沿用已完成的音频对齐。新增分析对分离后的鼓、贝斯与其他器乐声部计算频带起音：kick 346、snare 363、hat 747、guitar 866、bass 524、组合重音 278。

「guitar」是其他器乐声部中 500–6000 Hz 的起音代理，并非乐谱、MIDI 或逐音符人工转录；该代理驱动演奏相位和拨弦形变。Kick 驱动镜头和下沉，snare 驱动切口与小幅倾转，hat 驱动轻量数据反馈。不同层不共用一个等幅脉冲。

歌词的 SKY / FLAME / OCEAN / FREE / SATELLITE / HANDS / VOICE / IGNITE 等关键词成为字形点云、空间丝带、轨道与爆发事件。稳定的逐词中英阅读层在其下方保留。工具日志和程序界面是虚构的舞台语言。

## 输出与能力范围

全部画面原生 1920×1080 / 60 fps；11700 帧；195 秒。分为三个时间连续的片段并行渲染，H.264 CRF 14 编码，拼接只复制视频流；音频由原 MP3 一次编码为 AAC 320 kb/s / 48 kHz / stereo。MP4 放置 faststart 索引，支持直接下载后播放与按时间寻址。

本工程使用生成关键姿态、双向光流、距离场轮廓、局部变形、三维投影和程序几何。没有完整人体三维绑定，没有生成式视频模型，也没有将参考影片或《Bad Apple!!》片段混入成片。动画不是演奏指法的专业考据复现。

使用 Git LFS 交付高码率文件，保留 v2 下载，不以删除旧版本或强行压小文件的方式替代。验证的具体结果随 `validation-v3.json` 提供；这些技术检查不代表对艺术影响力、播放量或奖项的保证。
