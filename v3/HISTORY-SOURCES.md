# 历史间奏的原始出处

本片选择若干与「连接、学习、搜索、视觉、语言、开放」有关的节点，形成可穿行的想法版本树。这不是完整 AI 史，也不代表线性、唯一的发展路线。节点间的连线是艺术表达，不是技术继承关系的严格考证。棋盘和特征图均为程序绘制的象征性画面，不复刻历史棋谱或论文截图。

| 年份 | 画面主题 | 原始出处与表述范围 |
| --- | --- | --- |
| 1943 | 形式神经元连接成网 | McCulloch & Pitts, *A Logical Calculus of the Ideas Immanent in Nervous Activity*, [DOI](https://doi.org/10.1007/BF02478259) |
| 1950 | CAN MACHINES THINK? | Turing, *Computing Machinery and Intelligence*, [DOI](https://doi.org/10.1093/mind/LIX.236.433) |
| 1956 | Dartmouth 分支 | [Dartmouth 官方历史](https://home.dartmouth.edu/about/artificial-intelligence-ai-coined-dartmouth)。采用夏季研究项目举办年；提案写于 1955 年。 |
| 1958 | Perceptron | Rosenblatt, *The Perceptron: A Probabilistic Model for Information Storage and Organization in the Brain*, [DOI](https://doi.org/10.1037/h0042519) |
| 1986 | 误差信号逆流 | Rumelhart, Hinton & Williams, *Learning Representations by Back-propagating Errors*, [DOI](https://doi.org/10.1038/323533a0)。表示这篇重要论文，不宣称反向传播在此年首次发明。 |
| 1997 | 搜索树／国际象棋 | [IBM Deep Blue 官方历史](https://www.ibm.com/history/deep-blue)。Deep Blue 击败卡斯帕罗夫的对抗赛年份。 |
| 2012 | 特征层逐级展开 | Krizhevsky, Sutskever & Hinton, *ImageNet Classification with Deep Convolutional Neural Networks*, [NeurIPS 原文](https://papers.nips.cc/paper_files/paper/2012/hash/c399862d3b9d6b76c8436e924a68c45b-Abstract.html) |
| 2016 | 神经评价与树搜索 | Silver et al., *Mastering the Game of Go with Deep Neural Networks and Tree Search*, [DOI](https://doi.org/10.1038/nature16961) |
| 2017 | 词语彼此连接 | Vaswani et al., *Attention Is All You Need*, [arXiv](https://arxiv.org/abs/1706.03762) |
| 2020 | Few-shot Learning | Brown et al., *Language Models are Few-Shot Learners*, [arXiv](https://arxiv.org/abs/2005.14165) |
| 2024 | DeepSeek-V2 / MLA / MoE | [DeepSeek-V2 官方仓库](https://github.com/deepseek-ai/DeepSeek-V2)。代码 MIT 与模型许可是不同事项，片中不将 V2 权重标为 MIT。 |
| 2025 | DeepSeek-R1 / 开放分支 | [DeepSeek-R1 官方仓库与许可说明](https://github.com/deepseek-ai/DeepSeek-R1#6-license)。片中 MIT 标签指 R1 代码及 R1 权重，不对所有蒸馏模型的上游许可作概括。 |
